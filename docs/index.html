分析全程零联网 聊天内容 0 上传 本地优先 macOS

把你的微信聊天记录，
变成一份关系洞察工作台。

从本地微信数据里看到：谁最值得跟进、你的聊天节奏、语言风格， 还有一份基于聊天行为的人格与情绪画像。全程在你自己的电脑上完成，聊天内容永不出本机。

看示例报告（无需安装） 分享卡 GitHub

示例报告是一份滑动年报：整屏翻页，从概览、人格、情绪到待跟进一眼看完，适合分享。所有示例均由脱敏虚构数据生成，不含真实聊天内容。

关系工作台

总消息量、活跃会话、昼夜节奏、响应时延，压到同一个决策界面。

待跟进客户

把私聊里的提问、报价、负面反馈和疑似商机聚成一个待办列表。

人格 / 情绪画像

基于聊天表达风格的 MBTI 与情绪倾向（启发式，仅供参考）。

全本地

导出、分析、出报告整条链路零联网，由自动化测试守护。

Claude Code 插件

装成 Claude Code 插件后，用自然语言就能驱动整套导出与分析。

一行安装（macOS）
curl -sL https://raw.githubusercontent.com/caigee-cmd/wechat-insight/main/install.sh | bash

需要 macOS + 已登录的微信 Mac 4.x。详细步骤见 README。

或装成 Claude Code 插件
/plugin marketplace add caigee-cmd/wechat-insight /plugin install wechat-insight@wechat-insight

装好后直接对 Claude Code 说“分析我的微信聊天记录”“看看最近的客户线索”，就会触发 analyzing-wechat-chats skill，由它编排导出、分析和出报告。
